any2orca — Bambu Studio & PrusaSlicer 3MF to Snapmaker U1

any2orca converts Bambu Studio, Creality Print, Anycubic, ELEGOO, Flashforge, QIDI and PrusaSlicer .3mf projects for the Snapmaker U1, entirely in your browser. Multi-color painting, supports and the creator's print settings are kept, and your files are never uploaded.

How does local in-browser conversion protect my 3D models and IP?

Unlike online converters that upload your whole .3mf file to a server, any2orca runs entirely in your browser.

  • Your Files Never Leave Your Device: All parsing, coordinate recentering, preset translation, and archive stitching run locally in your browser memory.
  • No Uploads: Zero file, mesh, or vertex data is ever sent to any remote server.
  • Fast: there's no upload or download to wait for; the time a conversion takes is your own computer unpacking and repacking the file.
  • The command line works the same way: npx any2orca runs on your own computer, and nothing you convert is ever sent anywhere. Its only requests are a daily check for a newer version and, only if you turn them on, usage stats sent to a collector you set up yourself. any2orca telemetry show lists both, and the privacy guide shows how to check with your network turned off.

How to verify: Open DevTools (F12) → Network tab. Convert a file. You may see a request or two for the app's own code (such as a profile data file) loaded from this same site, which is normal. What to look for: no request contains your file's contents.

What does the "any" in any2orca cover?

Projects from Bambu Studio and the slicers built from it, Creality Print, Anycubic Slicer Next, ElegooSlicer, Flash Studio and QIDI Studio, and projects from PrusaSlicer, which has a project format of its own. Those seven are what any2orca converts today, each tested on a project saved by that slicer.

Projects that other slicers built on Bambu Studio save in its format are read the same way, but they aren't tested. Found another slicer whose projects convert, or one whose projects don't? Report it on GitHub. A project from a slicer built on PrusaSlicer with settings of its own, such as SuperSlicer, isn't converted: any2orca refuses it with a message and changes nothing. A 3MF that holds only the model, such as one saved by a CAD or modeling app, doesn't need converting: open it in Snapmaker Orca and choose a U1 profile.

Can I convert a Bambu 3MF to U1?

Yes! Drag any Bambu Studio, Creality Print, Anycubic, ELEGOO, Flashforge, QIDI or Prusa .3mf file into any2orca and it converts directly to U1 (Snapmaker U1) format in your browser, with no upload.

The conversion preserves your filament assignments, painted colors, and print settings while automatically adapting plate coordinates and clearance margins for the Snapmaker U1 build volume.

Are multi-color painted meshes and custom slicer settings preserved?

Yes, byte-for-byte on meshes: any2orca never touches <mesh>, <triangles>, or vertex paint XML structures (a PrusaSlicer project is the one exception: its mesh is rewritten into Snapmaker Orca's layout, one mesh per part, with the painting carried along). All multi-color paint, brush strokes, and filament slot assignments remain identical to the original designer's model.

Custom Slicer Settings:

  • Infill Density: Always carries over from your source file (sparse, skin, and skeleton infill).
  • Object Orientation: Never rotated during conversion, so orientation-relative settings like seam position stay correct exactly as the creator set them. Objects may shift slightly in X/Y for bed-fit centering, but never turn.
  • Customized Print Settings: Supports, support painting, and custom print settings carry over whenever explicitly customized by the author.
  • Speed & Acceleration: print speeds the creator changed carry over, up to the U1's machine limits, and you can set any that are above Snapmaker's stock back to stock. Accelerations and travel speed carry over only when they're lower than Snapmaker's stock, unless you choose to keep them.

How do I open the converted .3mf file in Snapmaker Orca?

The converted file names Snapmaker's own presets, so Snapmaker Orca opens it ready to slice; if it asks whether to keep the project's presets, keep them.

  1. Download the converted [ModelName]_U1.3mf file.
  2. Open Snapmaker Orca.
  3. Select File → Open Project... (or drag and drop the file into your slicer).
  4. Select a plate and slice!
