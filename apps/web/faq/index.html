Getting started

How does local in-browser conversion protect my 3D models and IP?

Unlike online converters that upload your whole .3mf file to a server, any2orca runs entirely in your browser.

  • Your Files Never Leave Your Device: All parsing, coordinate recentering, preset translation, and archive stitching run locally in your browser memory.
  • No Uploads: Zero file, mesh, or vertex data is ever sent to any remote server.
  • Fast: there's no upload or download to wait for; the time a conversion takes is your own computer unpacking and repacking the file.
  • The command line works the same way: npx any2orca runs on your own computer, and nothing you convert is ever sent anywhere. Its only requests are a daily check for a newer version and, only if you turn them on, usage stats sent to a collector you set up yourself. any2orca telemetry show lists both, and the privacy guide shows how to check with your network turned off.

How can I check that nothing is uploaded?

Open DevTools (F12) to the Network tab and convert a file; no request contains your file's contents.

You may see a request or two for the app's own code (such as a profile data file) loaded from this same site, which is normal. What to look for: no request contains your file's contents.

What does the "any" in any2orca cover?

It covers seven slicers: Bambu Studio and the slicers built from it, Creality Print, Anycubic Slicer Next, ElegooSlicer, Flash Studio and QIDI Studio, and PrusaSlicer, which has a project format of its own. Those seven are what any2orca converts today, each tested on a project saved by that slicer.

Projects that other slicers built on Bambu Studio save in its format are read the same way, but they aren't tested. Found another slicer whose projects convert, or one whose projects don't? Report it on GitHub. A project from a slicer built on PrusaSlicer with settings of its own, such as SuperSlicer, isn't converted: any2orca refuses it with a message and changes nothing. A 3MF that holds only the model, such as one saved by a CAD or modeling app, doesn't need converting: open it in Snapmaker Orca and choose a U1 profile.

Can I convert projects from slicers other than Bambu Studio?

Projects saved by Bambu Studio, Creality Print, Anycubic Slicer Next, ElegooSlicer, Flash Studio and QIDI Studio convert; they share one project format. Projects saved by PrusaSlicer convert too: its settings are translated to Snapmaker Orca's, an object's parts keep their filaments, painting is kept, a color change at a height becomes a pause (the U1 stops there for the swap), and variable layer heights are kept. A 3MF that holds only the model, such as one saved by a CAD or modeling app like Fusion or Blender, doesn't need converting: open it in Snapmaker Orca and choose a U1 profile.

Why this works: Modern slicers share the same underlying project archive structure and multi-plate configuration layout:

  • Bambu Lab: Bambu Studio & MakerWorld (X1C, P1S, P2S, H2C, H2D, A1, A1 Mini series .3mf).
  • Creality: Creality Print (K1, K2 Plus, Ender series .3mf).
  • Anycubic: Anycubic Slicer Next (Kobra series .3mf).
  • ELEGOO: ElegooSlicer (Centauri Carbon 2 .3mf).
  • Flashforge: Flash Studio (Creator 5 Pro .3mf).
  • QIDI: QIDI Studio (Q1 Pro, Plus4, X series .3mf).
  • Prusa Research: PrusaSlicer (MK3S, MK4, MINI, XL, CORE One and any other printer it has a profile for, .3mf).

Automatic Source Detection: You don't need to configure anything manually. any2orca automatically detects the source slicer and printer model, and carries over the settings the creator changed.

Can I convert a Bambu 3MF to U1?

Yes: Drag any Bambu Studio, Creality Print, Anycubic, ELEGOO, Flashforge, QIDI or Prusa .3mf file into any2orca and it converts directly to U1 (Snapmaker U1) format in your browser, with no upload.

The conversion preserves your filament assignments, painted colors, and print settings while automatically adapting plate coordinates and clearance margins for the Snapmaker U1 build volume.

How do I open the converted .3mf file in Snapmaker Orca?

Open Snapmaker Orca and use File → Open Project... (or drag the converted .3mf file into the window), then keep the project's presets if asked.

The converted file names Snapmaker's own presets, so Snapmaker Orca opens it ready to slice.

  1. Download the converted [ModelName]_U1.3mf file.
  2. Open Snapmaker Orca.
  3. Select File → Open Project... (or drag and drop the file into your slicer).
  4. Select a plate and slice!

Can I use any2orca without a mouse?

Yes: Everything works from the keyboard: Tab moves between controls, Enter or Space presses a button, and Escape closes any window or help popover. To convert without dragging, Tab to Choose 3MF File..., press Enter, and pick the file. Screen readers hear every control's name, and status messages and errors are announced. Options

What is Filament Brand Selection (Original vs. Generic vs. Snapmaker)?

Filament Brand Selection controls whether the converted file keeps the creator's filament names and settings or switches each filament to a preset that Snapmaker Orca ships.

Original keeps the creator's filaments exactly: their names and their settings. Generic and Snapmaker switch each filament to a preset Snapmaker Orca ships, with that preset's own settings, for uploads to Snapmaker Space; colors and order stay. Snapmaker Orca would use the preset's settings anyway once a filament carries its name.

  • Original (Default): Keeps the creator's filaments: names and settings as in the file (e.g. Bambu PLA Basic, Creality Hyper PLA, Anycubic PLA, Prusament PLA).
  • Generic: Switches each filament to a Generic preset Snapmaker Orca ships (e.g. Generic PLA), with that preset's own settings.
  • Snapmaker: Switches each filament to a Snapmaker preset Snapmaker Orca ships (e.g. Snapmaker PLA SnapSpeed), with that preset's own settings, for Snapmaker Space. Where Snapmaker makes no preset for that kind of filament (plain PETG, for example), the Generic one is used, and where neither fits the nozzle size, its name and settings stay as the creator had them.

What's the High Flow Hotend option, and should I turn it on?

Turn this option on for each toolhead where you have fitted the Snapmaker Liber High Flow Hotend, and leave it off for stock hotends.

Select the toolheads that have the Snapmaker Liber High Flow Hotend installed. Your converted file will record them, so Snapmaker Orca matches your printer. When you slice, Snapmaker Orca asks which colors print on which nozzle. Currently, only the 0.20mm Standard profile has faster high-flow speeds included. High-flow hotends help most on large prints with long, continuous paths; gains are smaller on fine detail, curves and frequent turns. View the Snapmaker Liber High Flow Hotend. It is only available for the 0.4mm nozzle.

Why does only 0.20mm Standard get faster speeds?

That's the only profile Snapmaker currently includes high-flow speeds for. Other profiles still work with high-flow hotends at their normal speeds, exactly as they do in Snapmaker Orca. If Snapmaker adds high-flow speeds to more profiles, conversions will pick them up automatically.

When should I turn on "Hardened steel nozzles", and why does it only appear for 0.4mm?

Turn it on if you installed 0.4 mm hardened steel nozzles on your U1; it only appears for 0.4 mm because Snapmaker's 0.2 mm, 0.6 mm, and 0.8 mm nozzles are all hardened steel already.

The stock U1 0.4 nozzle is stainless steel. Turn this on if you fitted hardened steel nozzles, so Snapmaker Orca warns about abrasive filaments correctly.

The switch only appears for 0.4mm because Snapmaker's other nozzle sizes (0.2mm, 0.6mm, and 0.8mm) are only manufactured in hardened steel, so the converter already records hardened steel for those profiles automatically.

Which nozzle size is my file converted for, and why did some filaments change?

Your file converts for the nozzle size selected in the sidebar (0.4 mm by default), and any filament tuned for a different nozzle size or diameter is updated to Snapmaker's values for the chosen size.

The converted file is made for this nozzle size: its profile, layer heights and filament values are the U1's for that size, and the file records it. The U1's stock nozzles are 0.4 mm. Snapmaker Orca uses one size for all four toolheads. A project made for another size is converted anyway and you're told; 'Match the file' converts for the size the creator used. When the size the creator used isn't installed on your U1, the printer refuses the job at print start.

A filament the creator tuned for another nozzle size keeps its name, color, temperatures and the other facts about the spool, but takes Snapmaker's preset's flow, max volumetric speed, pressure advance, retraction and cooling for the chosen size, since those were set for the creator's nozzle. The first note names the filaments; the colors are unchanged, so a preset of your own can be picked in Snapmaker Orca.

A filament the creator's printer took at another diameter (a 2.85 mm TPU tool) is set to Snapmaker's preset for its material, because the U1 takes 1.75 mm filament; the first note says to load 1.75 mm filament.

How do custom presets work, and how can I save my own settings?

A custom preset saves the print settings you tuned in Snapmaker Orca so you can apply them over Snapmaker's stock profile on future conversions under Advanced > Presets > Make Preset.

A preset is your own print settings, made from a project you tuned in Snapmaker Orca: walls, infill, supports, speeds and so on. Converting with it applies your settings instead of the creator's. It changes only what you changed from Snapmaker's stock profile; machine settings, filaments and the model's layout are never part of it. A preset applies to this conversion only: choose it again each time, or leave it on "No preset" for a normal conversion. Manage presets under Advanced.

Convert a file, open it in Snapmaker Orca, tune and save the project, then drop that saved file under Advanced > Presets > Make Preset. The settings you changed from stock are listed, you name the preset, and it's saved in your browser.

Once saved, your custom preset appears in the Preset picker beside the profile dropdown, for single files and batch conversions. You can also export your saved presets to a JSON file, to import them on another computer or to use with the any2orca CLI (any2orca presets import).

What does the Compare tool do?

The Compare tool lets you inspect parameter differences between two 3MF projects, between a 3MF file and Snapmaker's stock profile, or between a file and your saved presets.

Differences are grouped into print, filament, machine, and other settings. You can filter by search, show or hide identical parameters, and export the diff as JSON or copy it as plain text to share when troubleshooting.

If something looks different

Are multi-color painted meshes and custom slicer settings preserved?

Yes: multi-color painting, filament slot assignments, and the print settings the creator customized are all carried over into the converted file.

Byte-for-byte on meshes: any2orca never touches <mesh>, <triangles>, or vertex paint XML structures (a PrusaSlicer project is the one exception: its mesh is rewritten into Snapmaker Orca's layout, one mesh per part, with the painting carried along). All multi-color paint, brush strokes, and filament slot assignments remain identical to the original designer's model.

Custom Slicer Settings:

  • Infill Density: Always carries over from your source file (sparse, skin, and skeleton infill).
  • Object Orientation: Never rotated during conversion, so orientation-relative settings like seam position stay correct exactly as the creator set them. Objects may shift slightly in X/Y for bed-fit centering, but never turn.
  • Customized Print Settings: Supports, support painting, and custom print settings carry over whenever explicitly customized by the author.
  • Speed & Acceleration: print speeds the creator changed carry over, up to the U1's machine limits, and you can set any that are above Snapmaker's stock back to stock. Accelerations and travel speed carry over only when they're lower than Snapmaker's stock, unless you choose to keep them.

Why did the model position adjust on the build plate?

The converter recenters every plate onto the Snapmaker U1's 270 × 270 mm bed and tightens spacing if a layout from a larger printer would cross the bed edges.

Source printers have beds from about 180 mm to over 400 mm across; the Snapmaker U1's is 270 × 270 mm. any2orca automatically recenters your model to the center of the U1's bed. If a multi-part layout originates from a larger build volume and exceeds the U1's boundary at its original spacing, the engine gently tightens spacing around the shared center (never resizing any object) while maintaining a safe 5 mm margin from the bed edges.

If compaction brings objects close together (<2 mm tolerance) or if a single object exceeds the bed area, you will receive a clear advisory in the Conversion Notes.

Why does my converted file's layer height differ from the profile name?

When Snapmaker has no U1 profile for your file's exact layer height, the converter pairs the nearest profile for the rest of the settings while keeping your file's original layer height. For example, there's no 0.42mm profile for the 0.6mm nozzle; instead of changing your file's layer height to the nearest profile's, the converter keeps yours and adds a note saying so. If Snapmaker adds profiles for those heights later, they'll be in a later profile catalog update.

My older converted files open as "Project-inside presets" in Snapmaker Orca 2.4.0. Why?

Snapmaker Orca 2.4.0 renamed its U1 presets; for example, "0.20 Standard" became "0.20mm Standard". Files converted before October 14, 2026, by bambu2orca (the converter any2orca replaces), use the old names, so Snapmaker Orca can't match them to a system preset. Their settings are still correct. Re-convert them if you want them attached to Snapmaker Orca's system preset.

How does in-browser processing handle very large files?

Conversion runs in a background worker in your computer's memory for projects that unpack to up to 2 GB, so the page stays responsive while the archive is unpacked and repacked.

Because your files never leave your device, everything happens strictly inside your local web browser tab: the .3mf file is uncompressed directly into your computer's local memory (RAM) and processed entirely by your machine's CPU.

  • Zero Mesh Alteration: any2orca never modifies your 3D model geometry, polygons, or multi-color paint data. The heavy lifting is simply decompressing large zip archives, reading layout configs, and re-compressing the archive.
  • Stays responsive: conversion runs in a background worker, so the page keeps responding while a large file is unpacked and repacked. Very large projects need free memory; if one fails, close other heavy tabs and try again.
  • How large: projects that unpack to up to 2 GB convert here. Above 1 GB you'll see a note before converting, since it takes a minute or two and a few GB of memory. A project over 2 GB is refused with the reason; the command line converts larger ones (npx any2orca convert model.3mf --max-unpacked 4GB, up to 16 GB, needing about twice that much memory). The CLI reference has the details.
