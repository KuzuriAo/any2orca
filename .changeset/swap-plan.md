Features: **How a plate with more filaments than the U1 has toolheads prints on them.** A plate that uses five or more filaments but never more than four at the same height prints with a toolhead shared by two filaments, one after the other, with a pause between: at the pause the user unloads the first and loads the next, and the U1 purges and primes the new one on the prime tower. Until now the note only said such a plate "needs filament changes at pauses, which you set up in Snapmaker Orca". Now it says how: which filaments share a toolhead, where each prints, whether the project already has a pause between them and on which layer, where to add one if not, which filaments to load at the start, and that a filament coming in at a pause must be put on its toolhead by hand when sending the print (Snapmaker Orca's send screen matches filaments to toolheads by the loaded spools' colors, and that one isn't loaded yet). It also asks for a check of the sliced preview before printing, and says why: the layer numbers are worked out from the file, not from a slice, and a new layer height moves them. Layers are numbered from 1 as Snapmaker Orca's layer slider numbers them, worked out from the file the way Snapmaker Orca 2.4.1 builds them, variable layer heights and a layer height set for a range of heights (thicker first layers, say) included; for a plate whose layers the slicer builds its own way (a raft, supports with their own layer heights), the note gives heights in mm. A plate printed object by object gets no plan, since the slicer applies no pauses then. Checked against Snapmaker Orca 2.4.1's G-code of a real five-color project with a pause and of a color-by-layer print with thicker first layers, which the plan matches layer for layer, and against a print of the first on a U1; in a check of 482 real projects, 16 have such a plate, 6 of them with the pause already where it belongs. Converted files don't change. Library: `planFilamentSwaps()`, `report.swapPlans` (`SwapPlan`, `SharedToolhead`, `FilamentSwap`), and on each plate of `inspection.plateFilaments` and `report.plateFilaments` the filaments' `firstLayer` and `lastLayer`, the plate's `pauses` (`PlatePause`) and `byObject`. CLI: `inspect` prints each filament's layers, the plate's pauses and the plan, and `--json` carries `toolheads` and `swapPlans`. The plate-filaments example prints the plan.
