Features: **A Polymaker filament option.** Next to Snapmaker and Generic, `filamentComplianceMode: "polymaker"` (`--filament-compliance polymaker` on the command line) sets each filament to a preset Snapmaker Orca ships, the way the other two do, with Polymaker's first. Every PLA gets Polymaker's preset for its kind, whoever made it: silk PLA gets Silk PLA Family; PolyMax, PLA Pro and tough PLA get Tough PLA Family; any other PLA gets General PLA Family. Snapmaker Orca ships those three for the 0.4 mm nozzle only. A filament none of them fits gets what the Snapmaker option gives it: PETG, ABS, ASA, TPU, filled or wood PLA, and every filament on the 0.2, 0.6 and 0.8 mm nozzles. `report.filamentComplianceBrandFallback` lists those, and a note says so ("Polymaker makes no U1 preset for PETG, ABS and ASA at this nozzle size, so those get the preset the Snapmaker option gives them."). On a nozzle size with no Polymaker preset at all, `report.filamentComplianceBrandSizes` gives the sizes that have them, and the note says it once: "Snapmaker Orca has Polymaker presets for the 0.4 mm nozzle only, so every filament gets the preset the Snapmaker option gives it." Colors and order stay, as with the other options. Snapmaker Space's written review rules name Polymaker next to Snapmaker and Generic as the filament brands it accepts. The Snapmaker and Generic options convert as before: in a check of 482 real projects, the Snapmaker option converts every one exactly as 0.16.0 did. For UIs: `FILAMENT_COMPLIANCE_MODES` lists the options in the order to show them after Original (Snapmaker, Polymaker, Generic), and `filamentModeHasPresets(table, mode, nozzleSize)` says whether an option has presets of its own for a nozzle size (Polymaker: 0.4 mm only), and `filamentModeNozzleSizes(table, mode)` which sizes those are, so a UI can grey it out elsewhere and say why. `resolveFilamentName` takes the new mode and sets `brandFallback` when it falls back. The version note records the option, and a version note's `filamentComplianceMode` now reads as stamped whatever short name a later release writes there (older releases read a Polymaker file's note as no note).
