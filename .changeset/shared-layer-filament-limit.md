Features: **A note when a plate uses filament 17 or higher together with the filament numbered 16 lower.** Snapmaker Orca 2.4.1 can leave a filament numbered 17 or higher out of some of its layers, with no message, when the filament 16 numbers below it prints on the same plate (17 with 1, 18 with 2), and 2.4.0's source builds its tool order the same way; a fix is proposed in Snapmaker/OrcaSlicer#1208. any2orca keeps every filament and its number, so the file doesn't change: the conversion's notes now name the plate and the two filaments, say what the release does, and give the way around it (separate plates, or a number from 1 to 16 for the higher-numbered filament), so the sliced preview gets a look before printing. A filament 17 or higher that is alone on its plate, or there without that partner, gets no note: in test slices it printed every layer. The note follows the release the file is converted for: each release's entry in the profile catalog now says the highest filament number it prints in every layer whatever else is on the plate, read from that release's own source code when the profile data is generated, so a release with the fix has no limit and gets no note. Library: `ProfileCatalog.sharedLayerFilamentLimit` (16 for 2.4.0 and 2.4.1, null for a release without the limit). Profiles: `slicer.sharedLayerFilamentLimit` in each release's `index.json`. Converted files don't change.
