Features: **QIDI Studio projects are a supported source.** QIDI Studio saves in Bambu Studio's format, so its projects already converted; now they're tested (a QIDI Studio 2.7.2.73 save of the shared scene is a fixture) and named in the help, the README and the package description. The inspection's `sourceVendor` is `"qidi"` for them, read from the printer a filament preset names, since QIDI Studio writes its printer as "Q1 Pro". Converted files don't change.
