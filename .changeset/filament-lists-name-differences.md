Output-affecting: **Snapmaker Orca no longer warns about modified G-code when it opens a converted file, and a filament named like another printer's preset stays usable with the U1.** Since 0.10.0 each filament's list of changed settings named every filament setting, its start and end G-code included, and Snapmaker Orca warns about every G-code setting such a list names. Now the list names only the settings that differ from the preset Snapmaker Orca resets the filament to. Under Original, a filament whose name isn't one of Snapmaker Orca's U1 presets (a Bambu preset, say) gets the U1 preset the Generic option would choose as its parent: its name and the creator's values stay, it takes that preset's own filament G-code, and Snapmaker Orca no longer resets it to another printer's preset of the same name, which listed only that maker's printers. A filament no U1 preset fits names what the creator changed, what the conversion changed and the printers it can be used with. In the test projects, the Snapmaker and Generic options change only the lists; Original also gains the parents, and its filament G-code changes from Snapmaker's stock comment to the parent's own (a comment too, except for Snapmaker's Generic PLA Silk and its 0.8 nozzle Generic PLA High Speed, which set a fan).
