Profiles: **The settings of every filament preset Snapmaker Orca installs for the U1.** Each release's data has `filament-presets.json`, named by the index's `filamentPresets`: for each nozzle size, every filament preset Snapmaker Orca installs (129 for Snapmaker Orca 2.4.1, Snapmaker and Generic alike), resolved the way Snapmaker Orca holds it, stored as the values each printer's presets share and each preset's own. The Snapmaker and Generic filament options write them.
