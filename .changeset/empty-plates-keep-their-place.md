Output-affecting: **A project with an empty plate converts with every plate's objects on their own plate.** The converter laid out only the plates that had objects, but the file keeps every plate, and Snapmaker Orca puts an object on the plate whose area it's in: in a project with plates 1, 3 and 4 used and plate 2 empty, the objects opened on plates 1, 2 and 3, so per-plate settings, names and pauses went with the wrong objects. Each plate now goes to the place of its own number on the U1's grid, over every plate the file has, and an empty plate stays empty; empty plates after the last used one also count toward the grid's width, as Snapmaker Orca counts them. The conversion notes each empty plate ("plate 2 has no objects in the project; it stays empty, so the other plates keep their numbers"), and the report's plate count includes them. A PrusaSlicer project with an empty bed between used ones is placed the same way, with each bed's pauses on its own plate. In a corpus of 1,568 projects, 3 move (each has an empty plate before a used one, or an empty last plate that widens the grid) and 12 change only their plate count; no other converted file changes.
