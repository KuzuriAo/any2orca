Features: **A problem report to copy into a bug report.** Reporting a file that converts incorrectly used to mean describing it by hand, or attaching a model that isn't yours to share. Now the web app has **Copy report** on the result and on an error, the command line has `convert --report`, and the library has `problemReport()`: a short text with the any2orca and profile data versions, where it ran, the source project's slicer, printer and process preset, how many plates, objects and filaments it has, each filament's material, color and preset name, which filaments each plate uses, the options, the profile it was converted with or the error's code and the step it stopped at, and the conversion's notes. It is built on your machine and sent nowhere; you paste it where you choose. It never holds the file's name, object or plate names, a path or an error's message: preset names are cut at the "(name.3mf)" Bambu Studio adds to an edited preset, and a note's text is included only when its wording can't quote the file (any other note is listed by its topic). The bug report form now takes it as one box. Library: `problemReport()`, `describeEnvironment()`, `describeUserAgent()`, `PLAIN_NOTES`. The batch-script example writes one for each file that fails.
